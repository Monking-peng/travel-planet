## 功能边界

- 杭州、上海、武汉提供多人旅行：选景点、邀请、偏好、基础排程、方案接受与共同定稿。
- 其余目的地提供景观地图，包括日夜、自由旋转、近看地标和整组景点管理；没有借用原三城目录冒充当地旅行功能。
- 新地图以实拍为造型参考，采用程序化微缩模型。建筑和场地经过比例调整，不能当作地图导航、实地距离或工程复原。
- 参考照片只用于研究。各城参考文档保存来源和造型范围；公开资产为程序模型与产品截图。
- 自动化检查覆盖规则、几何、地面与水域避让、日夜及资源生命周期；另有实际网页截图和触控模拟。尚未完成 iOS、微信内置浏览器及低端 Android 真机验收。

具体测试范围见 [验收说明](TESTING.md)。源码和下载包以对应 GitHub Release 为准，不将旧压缩包称为当前线上版本。
