# 城市旅行图鉴

0.55.91 的视觉方向：以现有城市微缩模型为主角，使用青灰纸面、深绿文字和宋体城市名称。首页将城市与旅行操作放在左侧，完整星球放在右侧；手机顺序为城市、景观、操作。城市导航只展示杭州、上海、北京、广州，其他城市在原生对话框中选择，全部 22 城保持可达。

入场图片来自每座城市在当前渲染器中的实际画面，透明 WebP，保存在 assets/arrivals；只承担加载前的视觉过渡，不冒充可交互模型。CSS 动画使用 transform 和 opacity，首帧状态决定退出，不用假百分比或固定等待冒充加载完成。它改善等待反馈，不承诺缩短模型构建时间。跳过、Escape、资源失败重试、慢网提示和减少动态效果均保留。

杭州首页的初始取景单独调整为完整星球，既有地标模型不变，景观按钮可继续近看。旅行表单、邀请、偏好、方案与确认的业务逻辑保持，使用独立内存服务回归。

设计参考：[Anthropic 官方 frontend-design 技能](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)。采用贴合产品内容的视觉方向、真实资产、连贯入场与实际浏览器验收原则；不引入新的动画依赖。
